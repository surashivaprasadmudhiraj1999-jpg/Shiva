Complete setup guide

How I edit my videos with Claude Code

I record, drop the video in a folder, and paste one prompt. Claude Code does everything else: it removes gaps and background noise, adds captions (including Telugu–English “Tenglish”), a hook, zooms, animated app-screen demos, B-roll, sound effects and music, then renders the final video. This is my complete setup: every tool, skill, connector and prompt I use, step by step, so you can copy it.

00:30Before you start

What you need

  • A Claude Pro plan (or higher) and the Claude desktop app from claude.ai/download.
  • A Windows or Mac laptop. Mine has 8 GB of RAM, which is enough for 1080p Reels and long videos. Renders just take a while.
  • The kit: claude-video-editor-kit.zip (link in my description). It has the editing skill, scripts and all 3 prompts.
  • About 1 hour for setup, most of it waiting for downloads.
01:00Step 1

Set up Claude Code in the desktop app

  1. Open the Claude desktop app and sign in.
  2. Click the Code tab at the top. The editor doesn't run in Chat or Cowork.
  3. Click New session and choose Local, so Claude works on your own computer.
  4. Set permissions to Auto, so it doesn't ask you to approve hundreds of small steps.
  5. Pick the strongest model for setup.
  6. In Settings → Claude Code, turn on browser access, so Claude can capture real screenshots for B-roll.
02:00Step 2

Let Claude install everything

Unzip the kit. Start a new Code session with the unzipped kit folder selected, then paste this prompt. Claude installs the free tools (it asks before each one), sets up HyperFrames and Parakeet, installs the video-edit skill, creates your working folder and runs a test render.

Install prompt
Install the Claude video editor from this kit folder on my computer. Ask me before installing any software or model. Follow INSTALL-PROMPT.md in this folder step by step: check Node.js 22+, FFmpeg, Git and Python; create the engine folder; set up HyperFrames, its skills and the Parakeet transcription model; download GSAP and the fonts; make the sound effects; install the video-edit skill; create my "Videos/Claude Edits" folder with the prompts; run a test render; then tell me what's left for me to do.

When it's done you'll have:

# the engine: scripts, HyperFrames studio, sound effects claude-video/ # where you drop videos and paste prompts Videos/Claude Edits/ 1-short-reel.txt 2-screen-demo-reel.txt 3-long-youtube-video.txt # the editor's brain, loaded in every Claude Code session ~/.claude/skills/video-edit/ SKILL.md style.md screen-demo-style.md shooting-rules.md

Then fully quit and reopen the Claude app, including from the system tray near the clock. Skills only load when the app starts.

04:00Step 4

The skills (what makes it edit like a pro)

A skill is a file of instructions Claude reads before it works. This setup uses two sets:

video-edit (custom)

My full editing process: prep, noise removal, transcription, cutting gaps, captions, hook, zooms, screen demos, music, render and report. Its style.md holds my taste (colours, fonts, caption size, music level) and grows every time I give feedback.

screen-demo-style

Part of video-edit. When I explain steps in an app (Search Console, Claude, ChatGPT…), Claude rebuilds the screens as clean animations with a moving cursor, typing and a “STEP 1/5” label. They look much sharper than a raw screen recording.

HyperFrames skills

Installed automatically: hyperframes, -core, -animation, -audio, -keyframes, -creative, -registry, -cli, -studio and media-use. They teach Claude how to build animations and render video.

Check it worked: in a new Code session, type /vid. /video-edit should appear in the list.

05:00Step 5

Record so the AI can edit cleanly

Script first

Write your script, one sentence per line. It's the source for correct caption spelling and the plan for the edit.

Mistake → clap

Clap once, then restart the whole sentence. Claude keeps the last complete take.

Pause

About 1 second of silence after each line gives Claude clean cut points.

Name the pair

Video and script with the same name: topic.mp4 and topic script.txt.

Already trimmed it yourself? That's fine. The prompts tell Claude to do only a final clean-up of leftover gaps.

06:00Step 6

Edit a Short / Reel (my everyday prompt)

  1. Copy your video (and its script) into Videos/Claude Edits.
  2. In Claude: Code → New session → Local → select Videos/Claude Edits.
  3. Type /video-edit, paste the prompt below, and press Enter. Close Chrome first, because rendering needs the memory.

This prompt edits every video in the folder that doesn't have a “final” yet, so you can drop in several videos at once.

Prompt 1 · Short Reel
Edit every .mp4 video in this folder that does not have a matching "<name> final.mp4" yet, one at a time, into a premium 9:16 Reel.
If a script exists for a video ("<name> script.txt"), use it. Otherwise use the script pasted at the bottom of this message (if any).

- I already cut and trimmed these videos. Check them again: remove leftover gaps and silences, fix bad cuts, remove repeated words or mistakes, but keep the order of my lines.
- Remove background noise from my voice (clean but natural), then normalise the loudness.
- Captions word-by-word, spelled exactly like the script when there is one. If a line in the script is not spoken in the video, don't caption it. Show it on screen as a visual instead.
- If the video is 16:9, make it 1080x1920 with my video in the middle and a clean premium background on the top and bottom (no plain black bars).
- Hook in the first 2 seconds: a big bold title from the strongest first line, with a strong animation.
- A title card for each main point, zooms on important words, text pop-ups for key points, B-roll or animated app/chat screen demos wherever I mention a tool, website or example, soft sound effects, Epidemic Sound music low under my voice, and a "Follow" call-to-action at the end.
- Premium, clean, not busy. Make all the creative decisions yourself and don't ask me for approval.

Save each one as "<name> final.mp4" in this folder and give me a short report for each.

07:00Step 7

Reels with animated app-screen demos

For tutorial Reels (“open Search Console, click Performance, paste this…”), Claude rebuilds each app screen as a clean animation timed to your voice. You don't need perfect screen recordings. Screenshots are enough.

  1. Put the video in Videos/Claude Edits, for example regex hack.mp4.
  2. Make a folder next to it called regex hack assets and add:
    • Screenshots of each screen, in step order: 1.png, 2.png, 3.png…
    • Optional screen recordings: rec 1.mp4, rec 2.mp4…
    • Optional text.txt with the exact prompt or code to show typing on screen.
  3. Type /video-edit and paste:
Prompt 2 · Screen-demo Reel
Edit "PUT-VIDEO-NAME-HERE.mp4" in this folder into an ultimate, premium 9:16 Reel. My script is at the bottom. My screenshots, screen recordings and text are in the folder "PUT-VIDEO-NAME-HERE assets" (screenshots named 1.png, 2.png… in step order; recordings rec 1.mp4…; exact prompts/code in text.txt).

1. UNDERSTAND FIRST
- Watch and transcribe the whole video, read my script, and look at every screenshot and recording in the assets folder. Work out which step I'm talking about at each moment.

2. CLEAN-UP
- Remove gaps, silences, repeated words and mistakes so it flows naturally. Keep my order.
- Remove background noise from my voice (clean but natural) and normalise the loudness.

3. SCREEN DEMOS (most important)
- Follow your screen-demo-style.md rules.
- 0-3 sec: my face full screen with a big bold hook title.
- Whenever I talk about a step inside an app or website, switch to an animated recreation of that screen, timed exactly to my words: cursor moving, clicking, typing, dropdowns, copy, checkmarks. Build it from my screenshots so it looks like the real app. Use my screen recordings where they look clean; otherwise recreate the screen.
- During demos: only the screen (no face circle), the "STEP x / y" pill with a short heading, a progress bar on top, smooth zoom into the exact button or field, click ripples, and highlights on key values.
- Show any text from text.txt (prompts, code) typing out character by character.
- Last 3-6 sec: my face full screen again for the payoff and a "Follow" call-to-action.

4. EVERYTHING ELSE
- 1080x1920. If my video is 16:9, use the stacked layout with a premium background (no black bars).
- Word-by-word captions, spelled exactly like the script, shown while my face is on screen and kept away from the demo cards.
- Soft click, typing and pop sounds, whooshes between steps, and Epidemic Sound music (modern tech / lo-fi) low under my voice.
- Clean, modern, not busy. Make all the creative decisions yourself and don't ask me for approval.

Save it as "PUT-VIDEO-NAME-HERE final.mp4" in this folder and give me a short report: which demo is shown at which second, and anything I should check.

08:00Step 8

Long YouTube videos (16:9, 10+ minutes)

Record in Tella, which keeps your screen and camera as separate tracks. Trim it roughly in Tella, then let Claude do the rest:

  • Cold open: 30–60 seconds of the best moments up front as a hook, then an “In this video” card.
  • Layouts: your face full screen when you talk, and the screen full size with your face in a small circle during demos.
  • Polish: auto zoom into what you're explaining, highlight boxes, click sounds, and automatic blurring of emails and API keys.
  • Extras: chapter cards, an end screen, plus ready-to-paste YouTube chapters, title ideas and thumbnail frames.
Prompt 3 · Long YouTube video
Edit my long YouTube video (16:9, 1920x1080) using the video-edit skill.

VIDEO: My Tella video named "PUT-TELLA-VIDEO-NAME-HERE".
- Get it with the Tella connector: download the screen recording and the camera recording as SEPARATE files, with my Tella cuts applied.
- If the Tella connector doesn't work, use the screen file and camera file I put in this folder, and tell me what you used.
- My script is at the bottom of this message (or in this folder as "<name> script.txt").

1. CLEAN-UP (natural flow)
- I already trimmed it in Tella. Check again: remove leftover gaps, silences, unnecessary words, repeated sentences and long waits while pages load. Keep my order and make it sound smooth and natural, not chopped.
- Remove background noise from my voice (clean but natural), balance the voice level, and normalise the loudness.

2. COLD OPEN / INTRO HOOK (30-60 seconds, at the very start)
- 0-5 sec: the single strongest moment of the whole video (a surprising line or the best result on screen) with big bold text.
- 5-40 sec: 4-6 quick clips (3-6 sec each) picked from the full video: results, surprising statements, visual "wow" moments. Fast cuts, whoosh sounds, text pop-ups, energetic music. Don't give away everything.
- 40-60 sec: an "In this video" card with the 3 main things the viewer will learn, then a smooth transition into the main video.

3. LAYOUTS
- Talking parts (intro, explanations, outro): my camera full screen.
- Demo / screen parts: screen recording FULL SCREEN, with my face in a small circle in the bottom-right corner. If something important on screen is under the circle, move the circle to another corner.
- Switch layouts automatically, based on what I'm saying.

4. SCREEN RECORDING POLISH
- Auto zoom into the exact area I'm talking about (button, setting, chart, text), then zoom back out smoothly.
- Highlight boxes, arrows or underlines on important things. Soft click sounds on clicks.
- Blur any private info: emails, API keys, account names, passwords.
- If I talk about a website, tool, news or example that I didn't record, capture it with the browser (screenshot or scroll recording) and show it full screen.

5. GRAPHICS AND SOUND
- A chapter title card at the start of each section, and lower-thirds naming each topic.
- Text pop-ups for key points. Premium, clean, not busy.
- Captions: clean subtitles at the bottom, spelled exactly like my script (only lines I actually speak).
- Epidemic Sound music very low under my voice, a bit louder in the cold open and transitions. Soft sound effects.
- End screen (last 20 seconds): subscribe animation, leaving space for YouTube's end-screen video boxes.

6. RENDER AND DELIVER
- Render a quick draft first, check it yourself (frames, audio, black frames), fix problems, then render the final at 1080p.
- Save in this folder:
  - "<name> final.mp4"
  - "<name> chapters.txt" (YouTube chapter timestamps, ready to paste)
  - "<name> title-ideas.txt" (3 title ideas + a YouTube description)
  - 3 thumbnail frame suggestions as PNG images
- Make all the creative decisions yourself and don't ask me for approval. At the end, give me a short report: what you cut, the cold-open clips you picked, the layouts used, and anything I should check.

09:00Step 9

Teach it your style (this is the real secret)

Your first edit will be good. Your tenth will look like your channel, because every note you give becomes a permanent rule.

  1. Watch the final video and reply with notes that include timestamps:
Example feedback
At 0:04 the captions are too big, make them medium and simple. At 0:12 remove the face circle during the screen demo. Use a different premium background colour for each video. The music is too loud.
  1. When it looks right, say “save what you learned to the skill.” Claude writes the lesson into style.md and won't repeat that mistake.

Rules I've added this way include medium captions instead of huge ones, a different premium background colour per video, no face circle during screen demos, and playing the voice at 1.1× after removing pauses so it sounds natural. You can open style.md and edit it yourself at any time.

10:00Languages

Telugu, Hindi and other mixed-language videos

  • Always give your script. Claude uses Parakeet only for the timing of each word, and the spelling comes from your script. That's how my Tenglish captions (Telugu in English letters) stay accurate.
  • If a line in your script isn't spoken in the video (for example, an example you only want shown), Claude shows it on screen instead of captioning it.
  • Big multilingual models like Whisper large-v3 were very slow on an 8 GB laptop and less accurate for Telugu, so the setup avoids them by default.
11:00Fixes

Troubleshooting

ProblemFix
/video-edit doesn't show upFully quit the app (system tray too) and reopen it. Or start your message with “Use my video-edit skill”.
Render stuck at “frame 0”The laptop is out of memory. Close Chrome and other apps, then type “render again”.
Captions spelled wrongSave the script as <name> script.txt next to the video and say “redo captions from my script”.
Background replacement is slowCutting a person out of every frame is heavy (about 45 minutes for a 1-minute video on 8 GB). The prompt tells Claude to blur the background instead if it would take too long.
Big downloads stop halfwayKeep the Claude app open until they finish. Closing it stops background work.
Copyright claim on musicUse only Epidemic Sound or YouTube Audio Library tracks. Never use film songs.
