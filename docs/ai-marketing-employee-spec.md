# AI Marketing Employee (Project Context Document)

Version: 1.0
Status: Planning
Project Type: AI SaaS
Goal: Build a production-ready AI Marketing Employee that behaves like a real senior marketing professional rather than an AI content generator.

---

# Vision

Our mission is to build the world's first AI Marketing Employee.

This is NOT another ChatGPT wrapper.
This is NOT another AI writer.
This is NOT another marketing dashboard.
This is NOT another prompt library.

This software should behave exactly like hiring an experienced Senior Marketing Manager.

Instead of asking users to write prompts, the AI should understand the business, make marketing decisions, perform research, create strategies, generate content, monitor progress, and continuously improve.

The user should feel like they hired an employee instead of buying software.

---

# Core Philosophy

Current AI tools work like this:

User
→ Prompt
→ AI
→ Answer

Our product works like this:

Business
→ AI Understands
→ AI Thinks
→ AI Plans
→ AI Executes
→ AI Learns
→ AI Improves

The AI should proactively help the business instead of waiting for prompts.

# Non-Negotiable Rules

1. Never expose prompts to users.

2. Never expose internal agents.

3. AI always thinks before generating.

4. Strategy comes before execution.

5. Memory is permanent.

6. Every feature must save real business time.

7. Simple UX is more important than feature count.

8. Build production-quality code only.

9. Prefer scalable architecture over shortcuts.

10. Build as if this will become a billion-dollar AI company.
