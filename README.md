## How to Use This Curriculum

Each module file contains:
- **Learning Objectives** — Bloom's taxonomy-aligned measurable outcomes
- **Lesson Breakdown** — 5–8 lessons with concepts, case studies, AI tools, and pitfalls
- **Practical Tasks** — Portfolio-worthy assignments with AI-assisted and manual workflows
- **Assessment** — MCQ quiz, short-answer questions, and practical exam project
- **AI Prompt Library** — Ready-to-use prompts for real work
- **Resources** — Tools, free resources, and further reading

## Platform Import Notes

- All files are in Markdown (`.md`) for easy LMS import (Notion, Teachable, Thinkific, etc.)
- Headings use `##` / `###` / `####` hierarchy compatible with most LMS block parsers
- Quiz questions use structured format for SCORM-compatible parsing
- Rubrics use point-value tables for gradebook integration
